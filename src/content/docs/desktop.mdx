Shetu is a desktop SSH client for macOS, Windows, and Linux. It connects directly from your machine to your servers. The Shetu sync server you sign in to never proxies SSH traffic.

## Install

### One command

macOS and Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/nhridoy/shetu-client/main/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://raw.githubusercontent.com/nhridoy/shetu-client/main/install.ps1 | iex
```

The script detects your OS and architecture and installs the matching build. On Debian or Ubuntu it installs the `.deb`. Elsewhere it places the AppImage at `~/.local/bin/shetu`, which needs `libfuse2`.

### From a downloaded file

Download the build for your platform from [the download page](/download), or follow the step-by-step guide for [Windows](/download/windows), [macOS](/download/macos) or [Linux](/download/linux). The current release includes:

| Platform | Architecture | Format |
|---|---|---|
| macOS | Apple Silicon | `.dmg` |
| macOS | Intel | `.dmg` |
| Windows | x64 | NSIS `.exe` |
| Windows | ARM64 | NSIS `.exe` |
| Linux | x64 | `.AppImage`, `.deb` |
| Linux | ARM64 | `.AppImage`, `.deb` |

## First launch

Shetu is not notarized by Apple or signed by Microsoft yet. You will see a warning once.

**macOS:** drag Shetu to Applications, open it once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.

**Windows:** on the SmartScreen prompt, click **More info → Run anyway**. If your browser warns that the file is uncommon, choose **Keep**.

In-app updates do not repeat the warning.

## Connect your first host

1. Open Shetu and sign in or create an account. To use your own server, set **Server URL** on the sign-in screen first ([server guide](/docs/server#point-the-client-at-your-server)).
2. Choose **New host**.
3. Enter the hostname, port (usually 22), and username.
4. Choose the authentication method your server allows: password or private key.
5. Save the host and connect.

Shetu opens an SSH session in a tab. From the same workspace you can open an SFTP panel, split the terminal, and add port forwards.

## The vault

The vault stores credentials and keys encrypted on your device. Shetu derives a key from your account password with Argon2id and encrypts vault contents with XChaCha20-Poly1305.

Save the recovery kit Shetu gives you when you create your account, and store it somewhere safe. It is the only way back into your vault if you forget your password. Shetu cannot recover it for you.

## Updates

Shetu checks for updates from GitHub Releases. You can also download the latest build from [the changelog](/changelog). If an update fails, reinstall from the latest release.

## Uninstall

**macOS:** quit Shetu, move it from Applications to the Trash, then remove `~/Library/Application Support/com.nhridoy.shetu` if you want to delete local data.

**Windows:** uninstall Shetu from **Settings → Apps**, then remove `%APPDATA%\com.nhridoy.shetu` if you want to delete local data.

**Linux:** remove the AppImage, or remove the `.deb` with your package manager. Then remove `~/.local/share/com.nhridoy.shetu` if you want to delete local data.
