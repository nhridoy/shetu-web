# Terra SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Clean URLs, per-page metadata, share images and structured data across terra.iamnahid.com, plus new search-targeted pages and a build-time changelog.

**Architecture:** Stays a fully static Astro build served by Cloudflare Workers static assets. A page-metadata registry (`src/lib/seo.ts`) feeds `BaseLayout`, the share-image endpoint and a hand-written sitemap endpoint. Release data is fetched once at build time through the existing `getReleases`, falling back to the committed snapshot.

**Tech Stack:** Astro 7 (`output: 'static'`, `build.format: 'file'`), React islands (unchanged), Tailwind v4, Vitest, Biome, pnpm 12, Cloudflare Workers static assets (`wrangler.jsonc`). New deps: `satori`, `sharp` (explicit, already installed via Astro), `@fontsource/inter`, `marked`, `sanitize-html` (+ `@types/sanitize-html`). Removed: `@astrojs/sitemap`.

**Spec:** `docs/superpowers/specs/2026-11-11-terra-seo-design.md`

## Global Constraints

- Static output only. No adapter, no `main` in `wrangler.jsonc`, no new client-side JavaScript.
- Branch `seo` from `origin/main`; one PR at the end. Commits signed (global git config does it); no `Co-Authored-By` or "Generated with" lines anywhere.
- Gate per task: `pnpm lint && pnpm check && pnpm test && pnpm build`. Final task adds `npx -y wrangler@4.160.0 deploy --dry-run`.
- Copy: only claims inside the redesign spec's "Verified product facts"; `src/test/copy-guard.test.ts` stays green (no U+2013/U+2014, no banned claims).
- Never commit Satoshi font files. Never invent ratings, user counts or prices beyond the dated Termius table.
- The build must succeed when GitHub's API or Fontshare is unreachable.
- Release notes are untrusted input: render only through the sanitizer.
- Titles 30 to 60 characters; descriptions 110 to 160 characters.
- Works at 360px.

## Review Focus

1. GitHub API down or rate-limited during the Cloudflare build: changelog renders from `src/data/releases.json`, build succeeds. (Task 4 test.)
2. Fontshare unreachable during build: share images render with the Inter fallback. (Task 3 test.)
3. A release body containing raw HTML, `<script>`, or `javascript:` links: rendered notes contain none of them. (Task 4 test.)
4. A release with no assets, or a prerelease: its page renders, hides the downloads block, and labels the prerelease. (Task 5 test.)
5. Old URLs (`/download/`, `/releases`, `/releases/`): land on the new URL in one redirect. (Task 1 `_redirects` entries; manual curl after deploy in Task 9.)
